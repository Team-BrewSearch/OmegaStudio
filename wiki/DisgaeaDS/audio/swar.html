SWAR is Nintendo's DS wave archive: a set of SWAV samples that an SBNK refers to by index. In Disgaea DS they appear only inside DSEQ files.

Specification notes

  • A 0x3C-byte header, a u32 wave count at 0x38, absolute u32 offsets, then each wave as a SWAV without its 0x18-byte header.
  • In every shipped SWAR the waves sit back to back in table order from the end of the table, each exactly 0x0C plus (loop + non-loop words) x 4 bytes long.
  • A rebuild lays them out the same way and rewrites the file size and the DATA size (file size minus 0x10).
  • A wave shows as a SWAV whose header copies the SWAR's byte-order and version words.
  • All 138 SWARs rebuild byte for byte, also after every wave goes through WAV and back.

In OmegaStudio

Read as part of a DSEQ. Each wave shows as a SWAV child that plays, extracts and replaces from a SWAV or a WAV. All 138 shipped SWARs rebuild byte for byte, including after every wave goes through WAV and back.
