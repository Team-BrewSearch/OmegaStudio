DSARCIDX is the index-based archive used for every other .dat in Disgaea DS, and for the .dso files inside dspack.dat. It pairs a list of file IDs with an entry table that holds offsets and sizes.

Layout

+----------------------+   <-- 0x00
| ID list              |       u16 per file
+----------------------+   <-- rounded up to 4 with 0xFF
| Entry table          |       count entries, 512 bytes apart
+----------------------+
| File data            |       in entry order
+----------------------+   <-- EOF, on the same 512-byte step

Specification notes

  • The entry table starts after the u16 ID list, rounded up to 4 with 0xFF.
  • Both archive kinds place entries 512 bytes apart, counted from the first entry, and the file ends on the same step.
  • The gaps hold leftover junk, which a rebuild writes as zeros.

In OmegaStudio

The Disgaea plugin reads a DSARCIDX and lists each entry as a child, using the ID list to name them. Entries can be extracted or replaced, and the archive rebuilds byte for byte.
