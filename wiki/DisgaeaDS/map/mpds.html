MPDS is a compressed MPD map. All 198 maps in mpds.dat use it, and mpds.lst pairs each file name with its map ID.

Compression

LZ10. Back-references start at distance 2, and among equally long matches the farthest one wins. That is the game's own compressor: it rebuilds all 432 shipped .mpds and .dsm files byte for byte.

In OmegaStudio

An MPDS or DSM shows one decompressed child (MPD or .bin), and replacing that child compresses the new bytes with the game's own LZ10 compressor, which rebuilds all 432 shipped files byte for byte.
