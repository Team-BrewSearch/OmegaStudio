MPD is the tile-based map format shared by Disgaea and Disgaea DS. On the DS, maps ship compressed as MPDS.

Layout

A 16-byte header (u16 chunk count, u16 actor count), the chunks at 1408 bytes each (64-byte header with offset X and Z floats at 0 and 8, the tile count at 0x2C and an id at 0x30; 32 objects of 36 bytes; 16 event tiles of 4 bytes; a 128-byte base tile), then every chunk's tiles in chunk order at 128 bytes, the actors at 64 bytes, and a footer of two u32 lists, each led by its count.

Tile (128 bytes)

FieldOffsetDescription
Twelve 8-byte faces0x00-0x5Fu, v, v right, width, height, height right, texture, transform
Corner heights0x60Four corners X0Z0, X1Z0, X0Z1, X1Z1; -value / 12 is the height in tiles
Side bottoms0x64Side bottom heights
Visible0x70Visibility flag
X, Z0x71, 0x72Signed tile coordinates
Mobility0x77Mobility value (0, 1, 2)
Geo colour0x78Index into the Geo colour table
Geo panel0x79100 for a Geo panel, 0 for none

Faces 0 to 3 are the -Z, +X, +Z and -X sides (measured against which neighbour is lower over every map), 4 the top, 5 to 8 the side decals. A face's texture n is entry n - 1 of the footer's first list, an index into maptex.dat; 0, or an entry of 0xFFFF, is a face the DS does not texture. UVs are in half texels. Tops sample 16 x 16 cells of the prd atlases; sides tile the t textures.

Specification notes

  • The id is not a sequence: object-only chunks carry ids such as 2 or 3.
  • The 56-byte maps are empty Item World placeholders.
  • Chunk and actor counts are signed 16-bit; the chunk count is clamped to 6; chunks are copied at 0x580 bytes; each chunk's tile count is read signed from 0x2C; header bytes 4 to 15 are copied into the map state and never read again (the word at 4 is 0 or 1, a PS2 leftover).
  • 0x02042194 opens maptex.dat for the footer's first list and mapobjs.dat for its second, through 0x020426B4, which skips entries of 0xFFFF: the first list is the face textures, the second the object models.
  • Actors are read only by the spawner 0x0206028C: class and level signed 16-bit, side signed, X and Z signed with a world position of tile x 12 + 6 and no chunk offset, facing signed x 90 degrees, byte 8 an appearance condition, AI at 9, byte 10 multiplies the unit's stat, items 1 to 4 signed 16-bit at 12, spawn rule at 20, Geo effect at 22, one signed 16-bit weapon mastery at 24 for all seven weapon types, four spells at 26 and their levels at 34.
  • Still from the references rather than the code: the mobility names, the names of the Geo colours, which game stat +0x5B0 is, the face transform bits, and the object and chunk-header fields other than the offsets, the tile count and the id.

In OmegaStudio

An MPD opens in the Map tab: paint with Raise, Lower, Set height, Level and Fill height, Add tile, Erase tile, Stamp look, Mobility, Geo panel, Place, Move and Remove unit, and Place or Remove event tile. The Layer box tints cells by height, mobility or Geo panel, and Select shows every field of the cell's tile, units and event tile. The same map opens in the 3D view with textures from maptex.dat, unit markers coloured by alliance, Geo panels and event tiles. Tiles, Actors and Chunks list every record, selectable and editable. Export map as JSON writes every record; Replace map from JSON reads it back.
