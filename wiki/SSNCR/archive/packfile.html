Packfile.dat is the single archive every Shrek Smash n' Crash Racing disc ships. It opens on its own or in place inside a disc image.

Layout

+0x00  "PAK\0"
       entry count (u32)
       entry table: name hash, offset, size, ...
       file data, in table order
       zlib streams prefixed with "!CMP" carry a little-endian unpacked size

Entries

FieldDescription
Name hashHash of the entry's path; the original names are recovered by hashing candidate paths
OffsetByte offset of the payload from the start of the archive
SizeStored size; an entry beginning with !CMP is zlib-compressed and its first four bytes give the unpacked size

In OmegaStudio

The plugin reads the table and exposes each entry by its recovered name. Entries are extracted as their stored bytes. A !CMP entry is decompressed on read. The archive is read-only, so nothing is written back.
